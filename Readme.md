# 智能简历筛查管理系统 (ATS)

## 项目概述
本项目是基于 Django Admin 框架和 Django Jazzmin 主题构建的智能简历筛查管理系统，旨在帮助企业高效管理和筛选简历。Django Jazzmin 为系统提供了现代化的管理界面，具有响应式设计和丰富的自定义选项。

## 设计理念
我们的设计遵循现代企业级应用的美学标准，注重专业性、可用性和视觉舒适度。整体采用简约而不简单的设计语言，确保用户可以高效完成简历筛查工作。

## 配色方案

### 主色调
- 主要品牌色：`#2B5BA1` (深蓝色) - 传达专业、可信赖的企业形象
- 辅助色：`#4A90E2` (亮蓝色) - 用于重要操作按钮和交互元素
- 点缀色：`#34C759` (绿色) - 用于成功状态和积极反馈

### 中性色
- 背景色：`#F5F7FA` (浅灰蓝) - 为主要内容提供柔和的衬托
- 文字主色：`#2C3E50` (深灰) - 确保良好的可读性
- 次要文字：`#8492A6` (中灰) - 用于辅助信息
- 分割线：`#E4E7ED` (浅灰) - 用于界面分隔

## 响应式设计
- 断点设置：
  - 移动端：< 768px
  - 平板：768px - 1024px
  - 桌面：1024px - 1440px
  - 大屏：> 1440px

## 交互反馈
- 加载状态：使用简约的圆形加载动画
- 操作反馈：轻提示，持续2秒
- 弹窗模态框：背景遮罩透明度0.5

## 无障碍设计
- 符合WCAG 2.1标准
- 支持键盘导航
- 适当的颜色对比度
- 清晰的焦点状态指示

## 设计规范
所有组件和页面布局需严格遵循以上设计规范，确保整体视觉统一性和专业性。设计语言应体现：
- 清晰的视觉层级
- 一致的间距系统
- 专业的交互体验
- 舒适的视觉效果
