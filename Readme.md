# 智能简历管理系统

## 项目简介

本项目旨在为央国企构建一套基于检索增强生成（RAG）技术的智能简历管理系统。
系统充分利用最新的大语言模型（LLM）的推理能力和向量数据库的检索能力，提升人力资源管理效率。

## 技术栈

- **后端框架**：Django Admin
- **前端UI**：Django Jazzmin
- **数据库**：PostgreSQL
- **向量数据库**：Weaviate
- **大语言模型**：智谱AI、通义千问、Deepseek

## 功能特性

- **简历上传与解析**：支持多种格式的简历上传，自动提取关键信息并存储。
- **批量上传**：支持一次性上传多个简历文件，提升上传效率。
- **向量化存储**：将简历信息转换为向量表示，存储于Weaviate数据库中，支持高效相似性检索。
- **精准筛选**：将需要精准过滤的简历信息保存到向量库的metadata中，用于后续的精准筛查。
- **智能搜索与匹配**：根据职位要求，检索与之匹配的候选人简历。
- **自动化筛选与评估**：根据预设标准，对候选人进行初步筛选和评分。
- **个性化推荐**：根据职位描述和候选人简历，提供个性化的候选人推荐。
- **面试辅助**：为面试官提供候选人的详细信息和潜在问题，辅助面试过程。

## 环境要求

- **Python版本**：3.9及以上
- **Django版本**：3.x或4.x
- **PostgreSQL版本**：12及以上
- **Weaviate版本**：1.0及以上

## 安装与部署

1. **克隆项目仓库**：

   ```bash
   git clone https://github.com/yourusername/resume-management-system.git
   cd resume-management-system
   ```

2. **创建并激活虚拟环境**：

   ```bash
   python -m venv venv
   source venv/bin/activate  # Windows系统使用 venv\Scripts\activate
   ```

3. **安装依赖**：

   ```bash
   pip install -r requirements.txt
   ```

4. **配置数据库**：

   在 `settings.py` 中配置 PostgreSQL 数据库连接信息。

5. **初始化数据库**：

   ```bash
   python manage.py migrate
   ```

6. **创建超级用户**：

   ```bash
   python manage.py createsuperuser
   ```

7. **启动开发服务器**：

   ```bash
   python manage.py runserver
   ```

   访问 `http://127.0.0.1:8000/admin/` 登录后台管理界面。

## 使用说明

- **简历上传**：在后台管理界面，导航至“简历管理”模块，点击“添加”按钮，上传单个简历文件。
- **批量上传**：在“简历管理”模块，点击“批量上传”按钮，选择多个简历文件进行上传。
- **简历解析**：上传后，系统会自动解析简历内容，并提取关键信息。
- **候选人匹配**：在“职位管理”模块，创建职位描述，系统会根据职位要求，推荐匹配的候选人。
- **精准筛选**：在“简历管理”模块，标记需要精准筛选的简历项目，系统会将其保存到向量库的metadata中，用于后续筛查。
- **面试安排**：在候选人详情页，点击“安排面试”按钮，填写面试信息，系统会生成面试通知。

## 技术细节

- **Django Admin与Jazzmin**：利用Django Admin的强大功能和Jazzmin的现代化UI，构建直观的管理界面，方便人力资源管理人员进行日常操作。
- **PostgreSQL**：作为关系型数据库，PostgreSQL用于存储结构化数据，确保数据的完整性和一致性。
- **Weaviate**：作为向量数据库，Weaviate用于存储和检索简历的向量表示，支持高效的相似性检索。
- **大语言模型集成**：通过调用智谱AI、通义千问和Deepseek等大语言模型的API，实现简历解析、候选人评估和个性化推荐等功能。

## 部署与维护

- **云端部署**：考虑到数据存储和计算需求，系统可部署在云平台上，支持弹性扩展和高可用性。
- **持续优化**：定期更新模型和算法，优化系统性能和用户体验。
- **用户培训与支持**：为人力资源部门提供培训，确保系统的有效使用和维护。
